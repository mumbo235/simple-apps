# calc

a quiet, local-first calculator.

- **live**: https://mumbo235.github.io/simple-apps/calc/
- parentheses, unary sign, percent (value ÷ 100), decimals
- live result preview and a local calculation history
- full keyboard support
- history backup/restore and reset
- installable PWA with its own manifest, icons, and service worker
- no accounts, no ads, no tracking

## run locally

```bash
python3 -m http.server 8123
# open http://localhost:8123/calc/
```

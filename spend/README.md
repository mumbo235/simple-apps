# spend

a quiet, local-first spending log.

- **live**: https://mumbo235.github.io/simple-apps/spend/
- record amount, category, note, and date in one small sheet
- month totals, day groups, today total, optional monthly budget
- categories: food, transport, home, bills, fun, health, other
- currency display setting; JSON backup/restore and CSV export
- installable PWA with its own manifest, icons, and service worker
- no bank connection, no account, no syncing

## run locally

```bash
python3 -m http.server 8123
# open http://localhost:8123/spend/
```

# simple apps

a small collection of seven quiet, local-first web apps.

- **to:do** — https://mumbo235.github.io/simple-apps/to-do/
- **notes** — https://mumbo235.github.io/simple-apps/notes/
- **focus** — https://mumbo235.github.io/simple-apps/focus/
- **habits** — https://mumbo235.github.io/simple-apps/habits/
- **spend** — https://mumbo235.github.io/simple-apps/spend/
- **calc** — https://mumbo235.github.io/simple-apps/calc/
- **weather** — https://mumbo235.github.io/simple-apps/weather/

each app is its own installable PWA with its own manifest, icons, service worker, and local storage. the hub at the root is just links.

weather data by [Open-Meteo](https://open-meteo.com/).

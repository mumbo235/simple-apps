# habits

a quiet, local-first habit tracker.

- **live**: https://mumbo235.github.io/simple-apps/habits/
- daily check-ins, current and best streaks, a 14-day dot trail
- tap a habit for a month calendar; fill in any past day
- all data in `habits.*`; export/import JSON
- installable PWA with its own manifest, icons, and service worker
- no account, no streaks-as-guilt, no syncing

## run locally

```bash
python3 -m http.server 8123
# open http://localhost:8123/habits/
```

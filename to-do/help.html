back to to:do

to:do is installable and links directly to google calendar and gmail. this page covers install, linking, reminders, and the services used.

1. install

to:do is a pwa (installable web app). installing gives it an app icon and keeps it working offline. open to:do in your browser first.

  • iphone / ipad (safari): tap the share button, then add to home screen. open to:do from the new icon. notifications require ios 16.4 or newer and the installed app.
  • android (chrome): open the ⋮ menu and choose install app or add to home screen.
  • desktop (chrome / edge): use the install icon in the address bar, or ⋮ → install to:do. in edge it may be under apps → install this site as an app.
  • macos (safari): file → add to dock (sonoma or newer).

if you don't see an install option, use the browser menu → add to home screen. after installing, sign in and allow notifications once.

on first launch, a welcome card offers to link google and add to:do to your home screen. close it whenever you like.

2. link google

open the top-right menu, find sync, and tap sign in with google. choose the account you want to use and allow:

  • calendar — read/write calendar events. to:do reads upcoming events and adds an event when you save a dated task.
  • email — read-only gmail access. to:do only reads recent inbox metadata and short snippets to find actionable mail.

after signing in, the link calendar and link email toggles unlock. turn on the sources you want; both are on by default. stay signed in keeps the session alive between opens, and auto sync refreshes your list on load and every minute.

automatic reconnect: open the menu → advanced, paste the oauth client secret from google cloud credentials (or import the client json), then tap enable automatic reconnect and approve offline access once. to:do stores a refresh token on this device and renews without a popup. the secret stays on this device and is never exported.

if you would rather keep the client secret off this device, deploy the free token proxy to cloudflare workers, paste its url under advanced → token proxy url, and leave the client secret empty. the proxy holds the secret and exchanges codes/refreshes; the app still renews automatically.

if google still asks you to reconnect after about a week, set the oauth consent screen to in production; apps left in testing mode expire refresh tokens after 7 days. without a client secret, to:do keeps retrying the best-effort silent session and, after a few failures, asks you to reconnect from the menu.

to revoke access, open the menu → sync → disconnect, or use your google account permissions.

3. services

  • google calendar — events and dated tasks. open google calendar
  • gmail — actionable email. open gmail
  • openrouter — the ai that filters items into tasks; built in, no key needed. openrouter.ai

to:do doesn't link outlook, apple calendar, notion, or todoist directly yet. it reads your primary google calendar only, so events from other calendars need to be in that primary calendar to appear.

4. appearance

open the menu → appearance for mode, font, text size, density, animation speed, and reduce motion.

menu → colors sets the accent, background, and text colors. colors are saved separately for dark and light mode; match text keeps the accent monochrome, and reset restores the current mode. a custom background and text color automatically tint the cards and switches so the palette stays coherent.

menu → behavior can collapse the completed section by default, switch task times to a 24-hour clock, and turn vibration on or off. vibration is on by default on mobile, with different patterns for completing, undoing, adding, saving, deleting, switching lists, and errors. it uses the browser vibration api; android/chrome supports it, while iphone safari and most desktops do not. the vibration option is hidden on iphone. menu → sync shows the last sync, and menu → info shows the current build.

5. lists

the bar at the top switches lists. tap + to add one. the … button on a custom list lets you rename or delete it; deleting a list removes its tasks.

tasks you add go to the list you're viewing. email and calendar sync always creates tasks in my tasks, so automatic items stay together.

tasks whose due date has passed move into an overdue group above the list, marked with a red dot. complete them or move the due date forward to clear it.

tap the magnifier beside the menu to search every list. results show their list name; the × clears the query, and the magnifier or escape closes search.

6. reminders

open the menu → notifications → allow notifications. choose one or more remind before times; 5m and 30m are selected by default. turn sound on or off. each task has a bell in the add/edit sheet; the bell is on by default. reminders fire while to:do is open, including the installed app.

7. data

tasks, settings, and tokens are stored in your browser's localstorage. use menu → data → export for a backup. clear finished items with completed → clear, or erase everything with reset everything. see the privacy policy for details.

8. shortcuts

  • n or + — add a task
  • esc — close the add sheet or menu
  • tap the motto to cycle it
